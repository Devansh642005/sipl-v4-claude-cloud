# SIPL V4 experience handover

The approved SIPL Group-first corporate architecture, verified content and interaction logic are preserved. The existing V3 export is retained as `exports/sipl-group-pre-v4.zip`; no Git repository was available. No original production media was deleted.

## Presentation and interaction

The home page now combines a layered Varanasi hero, architectural drawing choreography, concise corporate story, verified snapshot, two business chapters, varied project presentation, interactive portfolio constellation, cinematic film preview, updates, project recognition and closing enquiry.

Shared royal navigation has a changing project image preview, state labels and refined mobile sheet. Discovery adds visual/index modes, keyboard selection, native swipe/drag and a selected project stage. About gains interactive principles; Culture and Careers gain an event-photo rail; Leadership retains verified portraits and adds expandable context. Recognition uses a dark exhibition treatment. Existing editorial Media/Blog, guided NRI, EMI and contact compositions retain their distinct layouts.

Sri Krishna Vilas uses a new entrance hero and selected high-resolution official renders, an amenity scene explorer, and the preserved master-plan, residence, gallery, document and enquiry tools. The approved silent film opens only after interaction, through one reusable theatre dialog with controls.

Krishna is a deterministic, image-aware digital concierge. It displays verified media and source descriptions, opens gallery/plan/film/enquiry destinations, and directs unsupported pricing, inventory, possession or legal questions to SIPL. No human employee is implied. No LLM/backend or secret is required.

Forms remain honest email-draft handoffs; no submission or booking confirmation is claimed. WhatsApp remains hidden because no verified number is configured. No fictional reviews, articles, awards, leadership or project details were added.
